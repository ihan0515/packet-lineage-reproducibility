# Packet-lineage reproducibility materials

This repository accompanies the fixed-MLP study of whether feature masking preserves training-strategy rankings observed after packet thinning and feature re-extraction.

The verified package contains ten numbered sections: data provenance; reference populations and exclusions; features and preprocessing; model configurations; splits and packet lineage; saved scores and thresholds; replay code and figures; environment; supplementary results; and release notes. Download the complete archive from Releases.

The saved-score replay verifies metrics, paired intervals, lineage checks and selection outcomes. Raw packet extraction and model training were not rerun for this release. Original PCAPs, full provider label files and trained-model pickles are not distributed. See the package README and third-party notices for details.

The MIT notice applies only to original project scripts; it does not license provider datasets. Repository hosting does not create an archival DOI.
